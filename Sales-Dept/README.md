# Sales-Dept - 営業活動拠点

## 取扱商材

### 1. ホームページ制作代行
- **ターゲット**: スマホ未対応の店舗（飲食店・美容室・整体院など）
- **フォルダ**: `01_HP制作代行/`

### 2. 深夜の自動予約チャットbot
- **ターゲット**: 人手不足の飲食店（居酒屋・焼肉店・ラーメン店など）
- **フォルダ**: `02_予約チャットbot/`
