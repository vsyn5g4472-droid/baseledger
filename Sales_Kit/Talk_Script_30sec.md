# 直接訪問用「即決」トークスクリプト

> **目的**: 施設長と会った最初の30秒で信頼を勝ち取り、「試してみよう」と言わせる
> **心理原則**: 返報性の原理（無料で価値を先に渡す → 断りにくくなる）

---

## フェーズ0: 訪問前の準備（超重要）

```
□ Target_Test_5.csv でその施設の「こだわり」を暗記する
□ 施設のWebサイトを直前にもう一度確認する
□ Googleマップで外観・周辺環境を把握する
□ 服装: スーツではなくビジネスカジュアル（親しみやすさ重視）
□ 持ち物: 名刺、スマートフォン（デモ用）、A4チラシ1枚
```

---

## フェーズ1: 最初の30秒 ——「この子の話、聞いてみよう」

### 受付での第一声

```
「お忙しいところ失礼いたします。
 天白区出身で、旭丘高校を卒業した越智萠希と申します。
 施設長の〇〇様に、1分だけお時間をいただけないでしょうか。」
```

**ポイント**:
- 「天白区出身」「旭丘高校」→ 地元の人間という安心感
- 「1分だけ」→ 心理的ハードルを極限まで下げる

### 施設長に会えたら（30秒トーク）

```
「〇〇施設長、お忙しい中ありがとうございます。
 越智萠希と申します。天白区で育ちました。

 〇〇様の施設が『△△（その施設のこだわり）』に
 力を入れていらっしゃることを拝見して、
 どうしても直接お伺いしたいと思いました。

 一つだけお聞きしてもいいですか——
 スタッフの方は、日報を書くのに毎日どれくらい時間をかけていらっしゃいますか？」
```

**ポイント**:
- 施設の「こだわり」に触れる → 「ちゃんと調べてきた」という信頼
- 質問で終わる → 相手に話させることで会話が続く
- 「日報」というピンポイントな課題 → 「あ、うちもそうだ」と共感を引き出す

---

## フェーズ2: 共感と課題の深掘り（1〜2分）

### 相手が「うちも1時間くらいかかってるよ」と答えたら

```
「やっぱりそうですよね……。
 僕の祖母も介護を受けていたので分かるのですが、
 スタッフの方って、利用者さんのために全力を尽くした後に
 さらに1時間デスクに向かって日報を書いてるんですよね。

 それが30秒で終わったら、
 その1時間を〇〇（施設のこだわり）に使えると思いませんか？」
```

### 相手が「うちはそこまで困ってない」と答えたら

```
「それは素晴らしいですね。運営がしっかりされている証拠です。
 ただ、もし仮に日報が30秒で終わったら、
 その時間で何をしたいですか？」
```

**ポイント**: 否定せず、未来の可能性を質問で引き出す

---

## フェーズ3: デモ（30秒）

```
「実は、スマートフォンに話しかけるだけで日報が完成するツールを
 開発しました。ちょっとお見せしてもいいですか？」
```

→ スマートフォンを取り出し、実際にデモを見せる

```
（スマホに向かって）
「今日の田中さんは、午前中のリハビリ体操に積極的に参加されました。
 食事は完食。午後は他の利用者さんと折り紙を楽しまれていました。
 特変なし。」
```

→ 生成された日報を見せる

```
「これだけです。特別なアプリのインストールも不要です。」
```

---

## フェーズ4: 返報性のオファー（クロージング）

```
「〇〇施設長、一つお願いがあります。

 このツールを、1週間だけ無料で使っていただけませんか。

 費用は一切かかりません。
 初期設定も、僕が直接お伺いしてお手伝いします。
 1週間使ってみて、合わなければそのままやめていただいて構いません。

 僕は、地元・名古屋の介護現場を少しでも楽にしたいんです。
 まずは試していただくことが、僕にとって一番うれしいことなので。」
```

**返報性のメカニズム**:
1. 「無料で設定までやってくれる」→ 何かお返ししなきゃ（= 試す）
2. 「合わなければやめていい」→ リスクゼロ → 断る理由がない
3. 「地元の学生が故郷のために」→ 応援したい心理

---

## フェーズ5: 日程確定

### 「いいよ、試してみようか」と言われたら

```
「ありがとうございます！
 では、初期設定にお伺いしたいのですが、
 今週と来週でしたら、どちらがご都合よろしいですか？」
```

**ポイント**: 「いつがいいですか？」ではなく「AとBどちらですか？」（二者択一法）

### 「ちょっと考えさせて」と言われたら

```
「もちろんです。
 ではこちらにご連絡先をお渡しさせてください。
 3日後くらいに、お電話で改めてご様子をお伺いしてもよろしいでしょうか？」
```

**ポイント**: 次のアクションと日時を必ず決めて帰る（「検討します」で終わらせない）

## 想定Q&A（よくある質問への切り返し）

| 質問 | 切り返し |
|------|----------|
| 「費用はいくら？」 | 「まずは1週間無料でお試しいただき、効果を実感していただいてからお話しさせてください。無料期間中に勧誘は一切しません。」 |
| 「ITに弱いスタッフが多い」 | 「スマホに話しかけるだけなので、LINEが使えれば大丈夫です。設定は全て私がやります。」 |
| 「個人情報が心配」 | 「利用者様のお名前は入力不要です。"Aさん""Bさん"で記録し、施設内で紐付けていただく形なので、情報が外部に出ることはありません。」 |
| 「上に確認しないと」 | 「もちろんです。よろしければ、上の方へのご説明にも同席させていただけますか？」 |
| 「今は忙しい」 | 「お忙しいですよね。チラシだけ置かせてください。来週、改めてお電話してもよろしいですか？」 |

## 訪問後のフォロー

```
□ 当日中: お礼メールを送る（「本日はお時間をいただきありがとうございました」）
□ 3日後: フォロー電話（「その後、ご検討いただけましたか？」）
□ 1週間後: 無料モニター中の場合 → 中間ヒアリング訪問
□ 2週間後: モニター終了 → 結果報告と本契約のご提案
```
