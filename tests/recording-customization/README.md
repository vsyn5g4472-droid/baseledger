# 記録カスタマイズ機能 — 実機（Expo Go）テスト手順

このドキュメントは **`feat/recording-customization`** ブランチを **Expo Go** で動かし、記録カスタマイズまわりの動作を確認するための手順書です。

---

## 前提条件

| 項目 | 内容 |
|------|------|
| 端末 | iOS または Android の実機に **Expo Go** をインストール済み |
| ブランチ | `git checkout feat/recording-customization` のあと `git pull` |
| 起動 | リポジトリルートで `npx expo start`（または `npm start`）し、QR を Expo Go で読み取る |
| ネットワーク | PC とスマホが同じ LAN（トンネル利用時は Expo の案内に従う） |

### 推奨（設定の永続化テスト用）

- **プロフィール → 設定** で使う「記録の表示」ON/OFF の **クラウド保存**は、**ログイン済みユーザー**のときに Firestore に保存されます。  
- **テスト 2（再起動後も保持）** を行う場合は、**必ずログインした状態**で実施してください。  
- 未ログインの場合はスクリーン上の注意どおり、その端末のセッション内のみの挙動になります。

---

## 準備: 詳細モードと各スイッチ

「バントの構え」「バント分類」「サイン」は **詳細モード OFF** のとき設定一覧に出ません。

1. **プロフィール（タブ）→ 設定** を開く。  
2. **「詳細モード」** を **ON** にする。  
3. 表示された項目のうち、確認したい機能のスイッチを **ON** にする（例: バントの構え、バント分類、サイン）。

**期待する結果**

- 「詳細モード」ON で、バント・サイン関連の行が一覧に追加表示される。  
- 各スイッチを切り替えてもアプリがクラッシュしない。

---

## テスト 1: 既存の試合データが普通に開けるか

**目的**: 新フィールドがない過去の試合データでも、読み込み・表示でエラーにならないこと（後方互換）。

### 手順

1. あらかじめ端末に **本アプリで保存済みの試合**（本ブランチ以前に記録したもの）が 1 件以上ある状態にする。  
2. **スコア** タブから **試合一覧 / 続きから** など、通常どおり **既存の試合を開く**。  
3. スコア画面で数秒操作し（イニング表示・打席が表示されれば十分）、必要なら **戻る** で一覧に戻り、別の試合も開いてみる。

**期待する結果**

- 試合を開いたときに **赤画面・クラッシュ・無限ローディング** が発生しない。  
- スコア画面の基本表示（表・裏、カウント、打席など）が従来どおり見える。  
- 新機能用のUIがオフのときは、従来と大きく乖離した挙動にならない（ON にしたあとの確認は「テスト 4」で行う）。

---

## テスト 2: 設定の ON/OFF → アプリ再起動 → 保持

**目的**: 記録表示設定が **ログイン時は Firestore に永続化**され、アプリ完全終了後も保持されること。

> **未ログイン**でこのテストをすると、端末内だけの挙動となり、再度ログイン方針と異なる可能性があります。**ログイン推奨**。

### 手順

1. **ログイン** した状態で **プロフィール → 設定** を開く。  
2. **詳細モード** を一時的に **ON** にし、分かりやすい項目（例: **ファウルチップ** または **併殺打**）を **意図的に反転** させる（ON→OFF または OFF→ON）。  
3. 操作が反映されるまで待つ（画面上部に短い **保存中** インジケータが出る場合あり）。  
4. 端末で **Expo Go を完全終了**（スワイプでアプリをキル / Android は最近のアプリから終了）。  
5. 再度 **Expo Go** を起動し、同じプロジェクトに接続してアプリを開く。  
6. 再度 **プロフィール → 設定** を開き、手順 2 で変えたスイッチの状態を確認する。

**期待する結果**

- 再起動後も、手順 2 で変えた **ON/OFF が維持**されている。  
- エラーダイアログ（「保存に失敗しました」等）が手順 2 の直後に出ていない。

---

## テスト 3: 新機能 — 概観

以下 **テスト 4〜7** では、スコア画面（ライブ中の試合）とプロフィールを使い、個別に確認します。

| 呼称 | 内容の目安 |
|------|------------|
| バント構え | 打席中に「バントの構え」トグルで ON にし、投球にバント意図が乗る |
| バント詳細 | インプレー確定時に **バント分類**（犠打・スクイズ等）を選べる（設定ON時） |
| サイン / プレー | **サイン** 設定ON時、打席・盗塁まわりでサイン種別を選べる |
| プレーメモ | 打席確定後のバーで **「メモ」** を開き、短文メモを保存できる |
| 成功率表示 | **プロフィール** に **バント・サイン** の集計カードが表示され、数値が読める |

---

## テスト 4: バントの構え

### 前提

- 設定で **詳細モード ON** かつ **「バントの構え」ON**。

### 手順

1. **新規試合** を開始するか、練習用の試合を開き、**打席中**（投球前）のスコア画面に置く。  
2. 画面上に **バントの構え** 相当の行（ボールアイコン等）が表示されていることを確認し、**タップで ON** にする。  
3. 通常どおり 1 球投球する（例: ストライク、またはインプレー）。

**期待する結果**

- バント構え行が表示され、ON/OFF を切り替えられる。  
- アプリが落ちない。  
- （ログ・編集画面まで追える場合）該当打席の記録に **バント意図（構え）** に関する情報が残っている、または従来どおり衝突しない。

---

## テスト 5: バント詳細（分類）

### 前提

- **「バント分類」** が ON。インプレーから **打席結果** を付ける流れ。

### 手順

1. 打席で **インプレー** に入り、フィールド/結果確定の流れで **打席を終了** させる。  
2. **バント分類** のモーダルや選択UIが出たら、**任意の分類**（例: 犠打、スクイズ等）を 1 つ選んで確定する。  
3. 試合を保存したあと、**プレイログ / 打席編集** 等で該当打席を開ける場合は、分類が保持されているか目視する。

**期待する結果**

- 分類選択の UI が表示される（設定OFFのときは出ない、または出ない旨が仕様どおり）。  
- 選んだ分類で確定でき、以降の表示で明らかな不整合がない。

---

## テスト 6: サイン（打席・盗塁）

### 前提

- **「サイン」** が ON。

### 手順

1. **打席中**、サイン用の **ピッカー / 行**（例: ヒットエンド runs、盗塁サイン等）を探し、**いずれか 1 つ** 選択する。  
2. 打席を通常どおり完了させる。  
3. 可能なら **盗塁** 操作用の画面で、盗塁サインを 1 件付与し、**セーフ/アウト** のいずれかで完了する。

**期待する結果**

- サイン用UIが表示され、選べる。  
- 確定時にアプリが落ちない。  
- 盗塁ログにサインが紐づく場合、後から確認できる、または他機能と矛盾しない。

---

## テスト 7: プレーメモ（打席確定スナック）

### 手順

1. 1 打席を **確定** させ、画面下部（または下付近）に **「✓ 打者名 …」** 形式の **確認バー** が出るまで進める。  
2. バー上の **「メモ」** をタップし、**数文字〜数十文字** を入力して **保存** する。  
3. **閉じる** 操作でバーを消す。

**期待する結果**

- 打席確定直後に確認バーが表示される。  
- 「メモ」から入力・保存ができ、プレースホルダ「メモ（最大200字）」が想定どおり。  
- 保存後に致命的なエラーが出ない。

---

## テスト 8: 成功率表示（プロフィール）

### 前提

- 上記のうち、バント or サイン付きの打席 / 盗塁が少なくとも数件、過去の試合データに含まれていると検証しやすい。  
- **プロフィール** タブに **バント・サイン** の集計（カード）が出る想定。

### 手順

1. **プロフィール** タブを開く。  
2. **バント** / **サイン** などの **成功率・試行数** が書かれた **カード** を探す。  
3. 数値が **0 ではない** データがあれば、目視で妥当かざっくり確認する。

**期待する結果**

- ログイン時、該当カードが表示され、**試行数 / 成功 / 率** などのラベルが読める。  
- 極端に常に 0% 固まる等の不自然さがない（データゼロの場合は 0 表示でよい）。

---

## 球速（参考）

本リリースの **記録表示カスタマイズ 17 項目には「球速」は含みません。**  
球速ストリップの表示は **試合ごとの `球速ON/OFF`（試合セットアップ / 速度設定）** だけで切り替わります。必要に応じて **スコアの試合開始前画面** で ON にして、スコア本画面の球速 UI の出し分けを別途確認してください。

## 補足

- バンドルや Metro の不整合が疑わしいときは、PC 側で `npx expo start -c`（キャッシュクリア）のあと、再度 QR を読み直してください。  
- `tests/emulator/` 下の **Firebase Emulator 用スクリプト**は、**クラウド Functions / ルール**向けの自動テストです。本 **Expo Go 手順**とは別枠です。
